Github contenant 3 fichiers :
il y en a 2 à exécuter :
  - config.bat [EN ADMINISTRATEUR] :
    ce .bat automatise une multitude de tweaks, astuces, optimisations, etc... 
    (notamment via les .reg) --> inspiré de capet mais compilé en un seul .bat convenant
    à mes idées d'un windows propre et optimal sans aller trop loin dans les manipulations.
- logiciels.exe
ce fichier .exe est un executable ninite qui permet d'installer automatiquement (hormis les
emplacement d'installation et les étapes à suivre "ok" , "continuer" , "accepter")
la liste de logicels : 
-chrome, notepad++, discord, winrar, vlc, et paint.net

résumé : 
executer config.exe en mode ADMINISTRATEUR 
executer logiciels.exe (pas besoin du mode admin)
